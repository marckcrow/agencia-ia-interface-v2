# Agência de IA Autônoma

Crie a estrutura inicial de uma interface administrativa moderna para o projeto Agência de IA Autônoma — Interface V2.

IMPORTANTE: este projeto é exclusivamente uma nova interface visual de um sistema existente. Não recrie o backend, banco de dados ou agentes.

O sistema original utiliza Node.js e possui APIs próprias. Posteriormente, esta interface será integrada a essas APIs.

Objetivos:

Interface profissional, responsiva e em português brasileiro.

Painel central de administração.

Gestão de três produtos: IA na Prática, Você Sabia? e Poder 50+.

Painéis para seis agentes de IA (A1 a A6).

Sala de Direção com aprovação humana obrigatória.

Calendário editorial.

Biblioteca de conteúdos.

Estúdio audiovisual.

Painel de execução e monitoramento.

Integrações e configurações.

Utilize React e TypeScript, com componentes reutilizáveis.

Nesta primeira versão:

Não conectar serviços externos.

Não configurar Supabase automaticamente.

Não criar banco de dados.

Não cadastrar credenciais.

Não implementar publicação automática.

Não utilizar APIs pagas.

Não modificar o repositório original.

Utilizar dados demonstrativos claramente identificados como simulação, somente para construir a interface.

Entregue inicialmente a estrutura visual e a navegação entre as telas, aguardando aprovação antes de implementar integrações reais.
